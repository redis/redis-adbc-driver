# Product-version wording erratum

Earlier records used “Redis Software 8.8” as shorthand for the database-reported
Redis 8.8.0 version. The retained older proofs identify the database version,
settings and image; they do not retain node API proof of the Software product
build. Their timings, settings and numbers are unchanged.

For this new measurement, the node management API explicitly reports Redis
Software **8.2.6-58**, while the database reports Redis **8.8.0**. The pinned image
digest and sanitized deployment settings are in [method.json](method.json).
Raw node/API evidence, credentials, fixture identities and operational artifacts
remain private. No product-build verification is retroactively invented for old
runs, and historical Community results remain labeled Community.
