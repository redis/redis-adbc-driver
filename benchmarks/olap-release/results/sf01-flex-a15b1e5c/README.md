# SF 0.1 on Software Flex, main `a15b1e5c`

Query records and metadata from one pass of each suite on 2026-11-26. The method, deployment and findings are in [the validation record](../../../../docs/sdlc/changes/sf01-flex-suites/validation.md).

**Read these labels with care:**
- The data is **SF 0.1**. The harness writes `"scale_factor": 1` into every `metadata.json` and reads the source from `<suite>-sf1.duckdb` whatever its scale.
- `metadata.json`'s `driver` field (0.0.31) is the installed wheel's version. The library was built from main `a15b1e5c` and loaded with `REDIS_ADBC_LIBRARY`; SHA-256 `730e4e7839f72291e35207c73b9a5e045d194bc14793a16ef16e6b464df4d362`.

Files:
- `sources.sha256`: the generated SF 0.1 sources (TPC-H and TPC-DS DuckDB files, SSB `.tbl` files).
- `<suite>/metadata.json`, `<suite>/queries.jsonl`: unchanged harness output, direct Redis ADBC and native DuckDB.
- `<suite>/queries.sha256`: SHA-256 of each exported, unmodified query file. The SQL itself is regenerated by `run.py --prepare-only`.
