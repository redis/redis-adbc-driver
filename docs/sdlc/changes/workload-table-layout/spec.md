# Contract

Measurement notes start collapsed behind a native, keyboard-accessible Details disclosure labeled with the execution ID. Notes remain plain text and participate in existing search, filters and sorting. Missing counters and explicit zero retain their meaning. Expanded text wraps within a bounded scrollable area; workload cells align at the top. No backend, telemetry collection, authentication or data changes.

See [intent](intent.md), [plan and validation](plan.md).
