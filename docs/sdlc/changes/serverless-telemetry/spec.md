# Contract and boundaries

See [intent](intent.md) and [plan](plan.md).

- API Gateway invokes a Python Lambda for existing public routes. Ingestion validates the existing allowlist and 64 KiB maximum. It acknowledges only a successful conditional S3 write or an already existing session/sequence object. Trusted API Gateway context supplies the observed IP; forwarded headers and client JSON cannot supply it.
- Session/sequence objects are immutable. Ingestion acknowledges buffering; cumulative counter/session consistency is checked by the worker. Invalid updates remain private in the recovery log and increment a rejection count without changing accepted counters. Duplicates, older sequences and retried jobs cannot double count.
- A single worker runs every 15 minutes. Checkpoints preserve accepted cumulative session state, exact report deltas/receipt times, deployment aliases, 10,000 execution samples, download snapshots and PTR cache. Workers retrieve only newly observed raw objects, retaining the existing report history in the checkpoint for exact rolling windows and retention.
- All traffic-filter summaries and their checkpoint publish through one conditional manifest write. Failed publication leaves the prior generation usable. The dashboard shows the actual generation timestamp. Delays and worker errors leave stale summaries visible rather than replacing them with partial totals.
- A create-only legacy baseline is mandatory for this existing deployment. Export only after redirecting ingestion and quiescing legacy writers. Preserve all historical delta rows and aliases, session state, execution IDs, download snapshots and cached PTRs. Continue comparing counts and IDs before switching public DNS.
- Existing dashboard bearer authentication is retained using an encrypted SSM parameter. Public ingestion requires no client secret. Tokens, AWS keys, report bodies and source addresses are never printed or committed. API access logs remain disabled. Separate function roles restrict data access; temporary migration privileges are removed after verification.
- Global API throttling replaces nginx's per-IP throttling; HTTP API does not provide the same per-IP controls. A two-second client timeout can still expire during cold start or slow S3 operations. A persisted-but-unacknowledged report is safe to retry.
- No report expiration is configured: historical receipt times and retention must not silently disappear. Worker size/time/object guards fail closed and retain the previous summary. Raw-object inventory and checkpoint cost grow with history; this is a bounded low-volume design, not an unlimited analytics warehouse. CloudWatch records worker failures; no notification recipient is invented.
- Terraform stages new resources before DNS cutover and pins the legacy AMI to avoid an unrelated replacement. The backup bucket remains protected. Stopping the legacy host removes compute charges; the unused Elastic IP is released and retained rollback disks must be accounted for separately.
