# Contract

See [intent](intent.md) and [plan](plan.md). Date: 2026-10-21.

Default new Cloud validation and benchmark deployments to Redis Cloud Pro.
Retain OSS and Redis Software compatibility checks. Use a dedicated disposable
non-production database with verified TLS, record the estimate and ownership,
and remove temporary resources after validation. Keep API keys and connection
credentials outside git and diagnostic output. Report untested deployment or
credential combinations as gaps.
