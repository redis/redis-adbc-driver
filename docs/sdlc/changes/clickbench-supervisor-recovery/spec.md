# Contract

See [intent](intent.md) and [plan](plan.md).

Adopt only the exact journaled statement unit after it finishes. Verify its job directory, binary digest, namespace, SQL, API, trial, raw-output directory and result path. Preserve the pre-recovery report, package-maintenance logs and timing-overlap provenance. Never restart the active scan or replace its measured time.

Resume only missing/failed identities through the existing scan controller. Preserve all final API outputs before cleanup. Budget exhaustion cannot conceal an unrelated timeout, OOM, worker error or correctness mismatch. Full acceptance still requires 18 successes and nine independently valid pairs.

The finisher’s explicit recovery entry point must validate the existing 48-shard backup, complete restore, topology/all rows and Q1–Q3 evidence, targeted acceptance and performance release. It waits for settled and preserved API work, checks no active scan, then performs the previously authorized exact-owned cleanup. It never reruns restore or the performance matrix.
