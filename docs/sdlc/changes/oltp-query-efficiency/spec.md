# Contract and acceptance

[Intent](intent.md), [plan](plan.md). Date: November 13, 2026. Status: implementation; human review pending.

Use Redis Software only with active/effective 4x QPF, six workers/mnp32, strict data TLS/RESP3 and recorded actual resources. Preserve storage protocol 17, snapshot pins and immutable visibility, external ownership/membership, private-output fences and atomic publication, exact NULL/precision/overflow behavior, context cancellation and uncertain-outcome no replay. Prepared or metadata reuse must revalidate live dependencies and catalog identity. Moving housekeeping must preserve worker-disabled and capacity/admission progress and explicit sweep semantics.

Record before/after full validated point/OLAP scenarios against the same owned fixture and frozen harness, separate profile instrumentation from latency samples, retain raw measurements, driver/harness hashes, all failures and actual source/settings. Quantify commands, round trips and phase timing for representative operations. Retain meaningful regression tests for each behavioral optimization, exercise concurrency and cancellation, run sequential Software checks with honest skips. Review correctness/lifecycle, security/ownership and evidence claims before PR.
