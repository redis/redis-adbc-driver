# Prefect

The Prefect adapter, examples, installation instructions and tests moved to
[redis-adbc-integrations](https://github.com/Redislabs-Solution-Architects/redis-adbc-integrations/blob/main/docs/integrations/prefect.md).

Install the separate `redis-adbc-integrations[prefect]` distribution alongside
`adbc-driver-redis`. Adapter imports now use `redis_adbc_integrations`
instead of `adbc_driver_redis`. See the destination README for source installation
until a release is published.
